## Việc cần làm

### 1. `src/game3d/manifest.ts` — manifest theo phòng
- Đổi tên type `StudentManifest` → `RoomManifest` (giữ alias `StudentManifest` để không vỡ import cũ).
- Thêm `url?: string` vào `ManifestItem`; import `junior.json`, `senior.json`; export `MANIFESTS: Record<StageId, RoomManifest>`, `getRoomManifest(stage)` (stage lạ → student), `itemByKey(stage, key)` (chỉ `items`). Giữ nguyên export `STUDENT_MANIFEST`, `ITEM_BY_KEY`.

### 2. Tạo `src/game3d/manifest/junior.json` + `senior.json` (phần lớn nhất)
- Cùng shape student: `{ version, character_scale, items, stage0: {items: [], hide: []}, poses }`.
- Mỗi file có 1 item `room_shell` với `url: "/models/room/<stage>/room_shell.glb"`, position [0,0,0].
- `items` chứa **mọi GLB keyreachable** trong phòng đó: bed, mattress, bed_vip, bed_floor_mat, nightstand, kettle, desk, table_folding (đặt được qua owned-tab), monitor, monitor2, keyboard, laptop, mug, cup, plant_small, lamp_desk, ergo_chair, chair_plastic, stool_plastic, fan_standing, plant_big, books_stack, poster_vn, fairy_lights, aircon. KHÔNG có window/floor_base/walls/wall_tiles (nướng trong shell).
- Toạ độ theo layout trong vỏ 4.45×4.45, sàn y=0.02: đồ treo tường (poster/fairy_lights/aircon) né đoạn cửa sổ trên tường sau, aircon đặt cao (~y1.9); mặt bàn y≈0.74, đồ socket nằm trên mặt bàn; nightstand cao ~0.6 để kettle đặt lên. Junior: giường trái-sau, bàn phải-sau, ghế trước bàn, shelf/tủ phải. Senior: giường trái, lounge trái-trước, thảm giữa, sideboard trái-sau + 2 appliance, bookshelf phải.
- `poses`: sit tại vị trí ghế phòng đó (độ cao calibrate theo student sit y=0.236), stand cạnh bàn, floor giữa phòng.
- ⚠️ Trước khi chốt toạ độ: đọc kỹ `resolveRoomFurniture` (slot-models.ts:147-243) để biết cơ chế spreading (`SHARED_SPOT_CATEGORIES`) lấy đa vị trí từ đâu — senior có 2 slot appliance cùng map `kettle`, 2 slot wall_art cùng map `poster_vn`; nếu 1 key = 1 vị trí manifest thì bổ sung override theo slot id cho stage.

### 3. Renderer stage-aware
- `ItemModel.tsx:43`: `url = item.url ?? itemUrl(item.key)` (nhánh character giữ nguyên).
- `RoomShell.tsx`: nhận `stage`, render `getRoomManifest(stage).items.filter(room_shell)`; student giữ 3 mesh (floor receive shadow), jr/sr 1 mesh shadows="both".
- `Furniture.tsx`: loop `getRoomManifest(stage).items` thay STUDENT_MANIFEST; block stage0 chỉ chạy cho student (điều kiện `stage0Active` đã student-only, giữ nguyên).
- `Player.tsx:44-46`: poses từ `getRoomManifest(stage)`.
- `lights.tsx`: `at()` dùng `itemByKey(stage, key)` + fallback stage0 (chỉ student); fairy-light Y per stage; gate đèn bàn theo `plan.drawn` như cũ.
- `assets.ts`: xoá comment "MVP renders the student room only"; `preloadAll` preload **cả 3 manifest** (dedupe URL, gồm shell) — GLB đồ là tập con của student nên chỉ thêm 2 file shell. KHÔNG thêm `room_junior/room_senior` vào `STORE_TO_KEY`.

### 4. `slot-models.ts` — map GLB + override theo phòng
- Thêm 22 entry `CATALOG_TO_GLB` (map gần nhất theo spec): bookshelf×2→nightstand, drawer_pedestal×2→nightstand, keyboard_mat×2→keyboard, laptop_stand→laptop, junior.mouse→mug, poster_1/2 + frame_1/2→poster_vn, junior.wardrobe→nightstand, armchair→ergo_chair, coffee_grinder→kettle, dual_monitor→monitor2, espresso_machine→kettle, monstera→plant_big, rug→bed_floor_mat, sideboard→nightstand, smart_speaker→mug, standing_desk→desk.
- `POSITION_OVERRIDES` + hằng số laptop (`LAPTOP_ON_FOLDING_TABLE`/`LAPTOP_ON_DESK`) tách theo stage; `resolveRoomFurniture` thêm tham số `stage = "student"` cuối (mặc định giữ nguyên chữ ký để 2 file test hiện tại gọi 3 tham số không vỡ).
- Giữ nguyên ngữ nghĩa `STORE_OVERLAY`, `AUTO_REPLACE`, `SHARED_SPOT_CATEGORIES`.
