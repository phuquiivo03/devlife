## Mục tiêu
Desktop (≥1024px): panel thông tin user bên phải cao đúng bằng card canvas trắng ở giữa — mép trên và mép dưới thẳng hàng theo thiết kế.

## Cách làm
Đo height card bằng ResizeObserver trong GameShell → truyền qua CSS var `--shell-panel-h` → `.column` dùng var này làm height (fallback/cap giữ nguyên). Không có feedback loop vì height card chỉ phụ thuộc width cột giữa.

## Thay đổi

1. **`src/components/game/shell-layout.config.ts`**
   - `shellPanelVars(layout?, panelHeightPx?)` — emit thêm `"--shell-panel-h": "${panelHeightPx}px"` khi có giá trị.
   - Cập nhật doc comment: panel phải theo height card giữa; `--shell-panel-max` vẫn là cap/fallback.

2. **`src/components/game/GameShell.tsx`**
   - Thêm `const [roomCardHeight, setRoomCardHeight] = useState<number | null>(null)`.
   - Thêm `useEffect` (deps `[assetsLoaded, hydrated]`): quan sát `areaRef.current` (phần tử `.room-canvas-slot` bọc đúng card trắng; height = card height ở desktop vì card luôn ≥ minHeight 270px) bằng ResizeObserver, set state = `Math.round(getBoundingClientRect().height)`. Cleanup disconnect.
   - Grid container (dòng ~184): `style={shellPanelVars(roomCardHeight ?? undefined)}`.

3. **`src/components/game/shell-layout.module.css`** — `.column` trong media ≥1024px:
   - `height: var(--shell-panel-h, var(--shell-panel-max));`
   - Giữ `max-height: var(--shell-panel-max)` (cap an toàn khi cửa sổ quá thấp), giữ sticky, `align-self: start`, z-index.

4. **`docs/design/DESIGN_SYSTEM.md`** — cập nhật đoạn Layout (dòng ~32) mô tả quy tắc mới: panel phải theo height card giữa, cap viewport chỉ là giới hạn an toàn.

## Hành vi giữ nguyên
- Mobile (<1024px): không đổi.
- Nội dung panel khi tràn height: scroll bên trong (`overflow-y-auto` sẵn ở PlayerInfoPanel).
- Fallback trước khi đo: hành vi cũ (viewport cap).
- Không đổi bố cục skills (list dọc 5 skills) — ảnh thiết kế thể hiện 2×2 với 4 skills nhưng dữ liệu thật có 5 skills; chỉ làm nếu user yêu cầu thêm.
